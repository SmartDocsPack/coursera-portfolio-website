# Single Page Developer Portfolio Website

A responsive, interactive single-page portfolio website built with **HTML5**, **CSS3**, and **JavaScript (ES6)**.

Created as part of the **IBM Generative AI Engineering / AI Developer Professional Certificate** on Coursera.

## 🚀 Live Demo
Visit the live portfolio: [https://smartdocspack.github.io/coursera-portfolio-website/](https://smartdocspack.github.io/coursera-portfolio-website/)

## ✨ Features
- **Sticky Navigation Bar:** Fast access to all portfolio sections with active hover states.
- **About Me Section:** Personalized introduction and bio overview.
- **Skills Grid:** Interactive CSS Flexbox cards showcasing technical proficiencies.
- **Projects Showcase:** Responsive cards with detailed feature bullet points.
- **Interactive Recommendations:** Dynamic DOM element creation and live insertion.
- **Interactive Modal Popup:** Confirmation dialog on recommendation submission.
- **Floating Scroll-to-Top Action:** Fixed home icon for fast viewport navigation.
